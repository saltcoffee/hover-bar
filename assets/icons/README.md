# Icon sources

These SVG shapes come from [Simple Icons](https://github.com/simple-icons/simple-icons), under [CC0 1.0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md).

- [wechat.svg](wechat.svg): [upstream shape](https://github.com/simple-icons/simple-icons/blob/develop/icons/wechat.svg), colored green for the WeChat Pay column.
- [alipay.svg](alipay.svg): [upstream shape](https://github.com/simple-icons/simple-icons/blob/develop/icons/alipay.svg), colored blue for the Alipay column.

Only fill colors and whitespace formatting were changed. These icons identify the available donation methods.
